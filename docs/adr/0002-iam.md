# ADR 0002 - Keycloak mais iam-admin-service
- Status: aceita
- Data: 2026-10

## Contexto
O enunciado exige provedor de identidade e governança de organizadores.

## Decisão
Keycloak emite e assina JWT e gerencia papéis; iam-admin-service cuida de solicitações, aprovação e auditoria, atribuindo o papel via Admin API.

## Consequências
Duas peças a manter; governança fica no domínio do projeto.
